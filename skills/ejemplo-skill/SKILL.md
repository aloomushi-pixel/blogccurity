# Instrucciones de la Skill

Aquí van las instrucciones detalladas de cómo el agente debe comportarse o qué pasos específicos debe seguir cuando se invoque esta skill.

## Dependencias
- Herramientas o scripts en la carpeta `/scripts`
- Recursos en la carpeta `/resources`

## Procedimiento
1. Analizar el contexto.
2. Usar los scripts de esta skill.
3. Devolver el resultado.
